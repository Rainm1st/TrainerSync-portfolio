TrainerSync Project Architecture
Four-layer stack: User Browser → GitHub Pages → Vite React SPA → Supabase · three trainee-facing feature modules.
User Layer

User Browser / PWA

  • Mobile browser or installed PWA (iOS / Android)
  • Requests compiled bundle from GitHub Pages on first visit
  • React SPA runs fully client-side — no page reloads
  • Persistent WebSocket to Supabase real-time
  • Offline-capable via Workbox service worker
HTTPS · bundle fetch
Hosting Layer

GitHub Pages (Static CDN)

  • Serves Vite-compiled output: index.html + hashed JS/CSS
  • No server-side rendering — purely static delivery
  • Base path: /CPT208-TrainerSync/
  • Deployed via GitHub Actions on push to main
  • Assets via vite-plugin-static-copy
loads into browser
Application Layer

Vite 5 + React 18 SPA

  • React 18.3 + TypeScript 5.7 · React Router v6
  • Tailwind CSS v4 · React Leaflet (gym floor map)
  • Zustand v5: auth · session · presence · social · chat
  • Exercise library: 30+ exercises, static JSON
  • vite-plugin-pwa + Workbox: installable, offline
  • Light / dark theme via localStorage
React 18 + TS Vite 5 Tailwind v4 Zustand v5 React Router v6
REST API + WebSocket
Backend Layer

Supabase Backend

  • PostgreSQL: profiles · sessions · hr_samples · session_presence · friendships · interactions · messages
  • Auth: JWT, row-level security
  • Real-time: WebSocket channels — presence & messages
  • Supabase JS SDK v2 — called directly from browser
PostgreSQL Auth (JWT) Real-time WS
Feature 1 — Plan

FR1: Workout Planning

Filter 30+ exercises by muscle group or equipment. Build a numbered session queue with set/rep programming. Reorder live during training. One-tap session launch.

Feature 2 — Monitor

FR2: Live HR + Session Summary

Heart rate tracked every 10 s with zone-aware display (blue · green · red) and breathing-cue overlay. After session: intelligent summary with HR timeline, sets done, and AI feedback.

Feature 3 — Connect

FR3: Buddy System + Gym Map

Real-time gym floor map (React Leaflet) with live zone occupancy. Message friends and anonymous strangers. Send connection requests to unlock full chat. Pre-book sets with peers.

Feedback loop: planned sessions feed live monitoring → post-session summaries improve future planning → connect features reduce wait times and sustain consistency.
